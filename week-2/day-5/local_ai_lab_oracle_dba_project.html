01 · Project overview

The main project is a local Oracle DBA assistant. The breakfast script is a small, separate LangChain exercise.

Foundation working

Oracle DBA AI assistant

Ask questions against indexed Oracle DBA notes. The app retrieves relevant chunks from Chroma and gives them to a local LLM as context. It also shows sources and scores and can decline to answer when retrieval is insufficient.

Breakfast prompt exercise

Uses LangChain's ChatOpenAI to request five healthy breakfast ideas. It demonstrates that invoke() returns an AIMessage, and that response.content is the reply text.

Learning style: make one small change, run it, inspect the result, and only then move to the next step.

07 · Separate exercise — breakfast.py

LangChain + OpenAI API; separate from the local Ollama RAG project.

Completed

Requirements covered

  • Single Python file: breakfast.py
  • Use LangChain ChatOpenAI, not the OpenAI SDK directly
  • Read the key from OPENAI_API_KEY, never hard-code it
  • Request exactly five healthy breakfast ideas
  • Numbered output, one line per idea, no preamble
  • Print only response.content after inspecting the full message object once
  • Run twice and compare results
Model and prompt used in the exercise
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0
)

prompt = """
Suggest exactly 5 healthy breakfast ideas.

Healthy means:
- Include a source of protein.
- Include fiber-rich whole grains, fruits, or vegetables.
- Prefer minimally processed ingredients.
- Limit added sugar.
- Provide balanced, practical breakfast options.

Format:
- Number the ideas from 1 to 5.
- Write one idea per line.
- No preamble or conclusion.
"""

response = llm.invoke(prompt)
print(response.content)

Key observations

invoke() returns a message

The first run printed an AIMessage with content and metadata such as token usage and model information.

Print the text only

print(response.content) outputs the reply text without the rest of the message object.

Temperature zero is not a guarantee

Two runs still produced different breakfast lists at temperature=0. It reduces variation but does not guarantee identical outputs across calls.

Define “healthy”

The prompt explicitly specified protein, fiber-rich foods, minimally processed ingredients, and limited added sugar. This makes the request more precise, though it does not guarantee clinical nutritional suitability.

If identical output is mandatory: store a fixed list and print it, or use stricter structured-output and validation logic. A prompt and temperature setting alone cannot guarantee exact repeatability.

Set the environment variable in the current Windows Command Prompt session:

set OPENAI_API_KEY=your_api_key_here
python breakfast.py

Replace the placeholder locally with your key. Never commit the key to source control or share it in screenshots.

08 · Roadmap to a safe Oracle DBA agent

Recommended learning sequence. Future items are not yet implemented.

1

Evaluate retrieval quality Next

Build a repeatable question set, record expected sources, review false matches, and tune retrieval based on evidence.

2

Expand trusted Oracle documentation

Add approved manuals, team runbooks, and error-specific troubleshooting documents. Track source, version, and update date.

3

Analyze diagnostic files

Build evidence-based analysis for alert logs, Oracle errors, SQL plans, and selected reports. Redact secrets and sensitive data.

4

Add read-only tools

Use validated, allow-listed diagnostics and structured results. Start with mock data or a non-production database.

5

Add safety and audit controls

Require least privilege, input validation, timeouts, logging, explicit approval for state changes, and a tested rollback plan.

Production safety: Do not let the model execute arbitrary SQL or make production changes autonomously. Start with read-only tools in a test environment and keep approval gates outside the model.
