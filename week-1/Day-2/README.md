# SE-AI_Program

Once you run the script in VS Code or your terminal (python Student_Grade_Manager.py), follow these prompts step-by-step:

Number of Students:

    Enter how many students you want to grade (e.g., 3).

Student 1 Details:

    Name: Type the student's name (e.g., Alice).
    Marks: Enter their total mark out of 100 (e.g., 85.5).

Student 2 Details (and so on):

    Name: Enter the next student's name (e.g., Bob).
    Marks: Enter their mark (e.g., 92).
